    {{ icon("record", "icon-sm text-subtle") }}1. Запись роликов

    Длительность

    Модель смотрит на 6 секунд движения человека, поэтому ролик должен быть длиннее и действие — идти почти весь ролик.

    Как записать хороший датасет
    • Инсценируйте действие с участниками, которые согласны на съёмку: толчки, удары по воздуху, борьба, захват.
    • Весь человек должен быть в кадре, без долгих перекрытий.
    • Меняйте людей, одежду, ракурсы, освещение и места в кадре.
    • Запишите столько же «Нормы» на тех же камерах: разговоры, проходы, объятия, рукопожатия, суету. Иначе модель будет видеть драку в любой активности.
    • Неудачные дубли удаляйте из списка роликов в карточке «Датасет».
